# Regression Corpus

JSON files in this directory store known-interesting boolean test scenarios for replay testing.

## Format

Each `.json` file is a `CorpusEntry`:

```json
{
  "id": "K8",
  "description": "Three bosses then three cuts — complex chained boolean",
  "status": "Pass",
  "scenario": {
    "body_a": { ... },
    "body_b": { ... },
    "op": "Union"
  },
  "expected_topology": [24, 36, 14],
  "expected_volume": 950.0
}
```

## Status values

- `Pass` — Test is expected to pass
- `Fail` — Known bug, test expected to fail
- `Ignore` — Skipped (too slow, flaky, etc.)

## Adding entries

Entries are auto-generated by proptest shrinking when a failure is found.
They can also be manually created for known regression cases.
