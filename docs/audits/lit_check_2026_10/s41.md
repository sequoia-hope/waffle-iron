### Justifications for All 8 Status Changes

1. **`3-01` (`FAITHFUL → PARTIAL`)**
   - **Paper (`refs/text/yang2025_hybrid_boolean.txt:211-212`):** *"We establish a bijection between the B-Rep model and the triangle mesh using hybrid representation. Our inputs are B-Rep models, which are mapped to a triangle mesh through error-bound discretization (a)."*
   - **Code (`crates/yang-rs/src/brep.rs:893, 1504-1518`, `crates/yang-rs/src/stage1_tessellate.rs:511, 1706-1710, 1971-1974`, `crates/yang-rs/src/stage1_tessellate/surface_face_tessellators.rs:85-92, 238`):** `BRep::from_topology_and_tess` (`brep.rs:893`) constructs `TessellationMap` (`:300`) and `tri_face` (`:552`), but (i) Stage-1 discretization is not error-bounded on cone charts (`ChartBudget::default()` at `surface_face_tessellators.rs:238`, `stage1_tessellate.rs:4171-4174`, `N61`), rests on an empirical corpus measurement on spheres (`0.82·d_ε`, `:85-92`), and omits `d(T)` on boundary triangles (`4.1-24`, `N93`); and (ii) on `Curve::SurfacePair` boundary chains (`stage1_tessellate.rs:1706-1710, 1971-1974`), `TessellationSource::BRepEdge { edge, t }` stores an ordinal index fraction `(i + 1) / (m + 1)` that `BRep::eval_source` (`brep.rs:1504-1518`) evaluates by 3D chord linear interpolation `(1 - t)·start + t·end`, returning an off-surface point rather than inverting a bijection. Grading `3-01` `FAITHFUL` contradicted `4.1-01` (`PARTIAL`).
